# 📚 Librería Virtual UTP – Sistema Supervisor

Este es el proyecto final del curso de **Lenguaje de Programación**, que implementa un sistema de gestión para **pedidos, entregas y mantenimiento de clientes/productos** para la _Librería Virtual UTP_.

El software fue desarrollado en **Python**, utilizando **Tkinter** para la interfaz gráfica y **Pandas** para el análisis y generación de reportes.

---

## Requisitos del Sistema

Para ejecutar la aplicación, debes tener instalado **Python 3.x**.

---

## Instalación de Librerías

El proyecto utiliza la librería `pandas` para la funcionalidad de análisis de datos.
Instálala ejecutando:

```bash
pip install pandas
```

---

## Ejecución de la Aplicación

- Asegúrate de haber instalado pandas.

- Navega a la carpeta raíz del proyecto. ```src/libreria-utp/```

- Ejecuta el archivo principal:

```python
python main.py
```

## Credenciales de Supervisor (Login)
